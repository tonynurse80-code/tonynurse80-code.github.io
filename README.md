# Tony Munyua Mwangi — Portfolio

A responsive personal portfolio built as static HTML and CSS for GitHub Pages. It uses the selected Figma Community portfolio as a structural reference and presents Tony's nursing education and healthcare AI evaluation practice in an original visual design.

## Publish with GitHub Pages

This site is intended for the public repository `tonynurse80-code.github.io`. The entry file, `index.html`, belongs at the repository root alongside `styles.css`.

In GitHub, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then save. The public site address is `https://tonynurse80-code.github.io`.

## Content notes

- Healthcare examples are fictional practice cases, not clinical advice.
- The project work is described as portfolio practice and in progress.
- No patient information, private contact details, passwords, or certificate scans are included.
- Review all public profile details before sharing the site.
